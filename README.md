# God's Will Evening School

Management system for God's Will Evening School.

## Stack
- Next.js 16
- React 19
- Supabase
- Vitest

## Setup
1. Copy `.env.example` to `.env.local` and fill Supabase values.
2. Install dependencies: `npm install`
3. Run dev server: `npm run dev`

## Commands
- `npm test -- --run`
- `npm run lint`
- `npm run build`

## Phases
- Phase 2: School core
- Phase 3: Finance
- Phase 4: Attendance
- Phase 5: Examinations and GCE academic structures
